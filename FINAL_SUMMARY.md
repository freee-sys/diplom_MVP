## 🎯 Функциональные возможности

### ✨ Что может сделать пользователь?

1. **Создать соединение между интерфейсами:**
   - Открыть элемент → Интерфейсы
   - Выбрать Level (L2/L3/L2/L3)
   - Выбрать Reverse Interface из dropdown
   - Сохранить → Соединение создано!

2. **Увидеть соединение на топологии:**
   - Перейти в вкладку "Topology"
   - Видеть цветные линии между элементами
   - Цвет зависит от уровня

3. **Фильтровать соединения:**
   - Открыть dropdown "Connection Level Filter"
   - Выбрать нужный уровень (L2/L3/L2/L3)
   - Видеть только нужные соединения

4. **Проверить статус соединения:**
   - Открыть таблицу интерфейсов элемента
   - Видеть колонку "Connection"
   - Зеленый/синий/фиолетовый текст = подключено

5. **Изменить или удалить соединение:**
   - Отредактировать интерфейс
   - Изменить уровень
   - Изменить противоположный интерфейс
   - Или выбрать "-- No Connection --" для удаления
