# UI Redesign - Element Editor Implementation

## Overview
Решена проблема с глобальным отображением интерфейсов. Реализована новая архитектура с отдельным модальным компонентом `ElementEditor` для создания и редактирования СЭ с их интерфейсами.

## Что изменилось

### 1. Новый компонент ElementEditor.js ✅
- **Файл:** `frontend/src/components/ElementEditor.js`
- **Размер:** ~400 строк
- **Функции:**
  - Модальное окно для создания новых СЭ
  - Модальное окно для редактирования существующих СЭ
  - Встроенное управление интерфейсами внутри модального окна
  - Управление подключениями между интерфейсами (L2/L3)
  - Полная изоляция управления интерфейсами для конкретного СЭ

**Основные отличия:**
- ✅ Интерфейсы добавляются/редактируются ДО сохранения СЭ (для создания)
- ✅ Интерфейсы добавляются/редактируются/удаляются в отдельном окне (для редактирования)
- ✅ Полная форма с валидацией
- ✅ Таблица интерфейсов внутри модального окна
- ✅ Иконки для быстрого редактирования/удаления интерфейсов

### 3. Обновлён App.js
**Изменения:**
- `showForm` → `showEditor`
- Убрал `ElementForm` из импорта
- Добавил импорт `ElementEditor`
- `handleCreateElement` переделана для работы с полным объектом элемента
- `handleUpdateElement` переделана для работы с модалью
- Добавлена условная отрисовка `ElementEditor` при `showEditor === true`
- Обновлены обработчики для работы с новой архитектурой

**Новая логика:**
```
App.js state:
- showEditor: boolean (открыть модаль редактора)
- editingElement: null | element (какой элемент редактируем)

Логика:
- Клик "New Element" → editingElement = null, showEditor = true → ElementEditor создание
- Клик Edit на элементе → editingElement = element, showEditor = true → ElementEditor редактирование
- Save в ElementEditor → вызовет handleCreateElement или handleUpdateElement
- Cancel в ElementEditor → showEditor = false, editingElement = null
```

## Как это решает проблему интерфейсов

**Старая архитектура (ПРОБЛЕМА):**
```
App.js
├── LeftPanel
│   ├── ElementList → клик → setSelectedElement
│   └── ElementForm (inline)
├── RightPanel
│   ├── ElementDetails
│   │   ├── Inline редактирование элемента
│   │   └── InterfaceTable (может быть путаница с состоянием)
│   │       └── Может отображать интерфейсы глобально ❌
```

**Новая архитектура (РЕШЕНИЕ):**
```
App.js
├── LeftPanel
│   ├── ElementList (кнопки Edit)
│   └── Без inline ElementForm ✅
├── RightPanel
│   ├── ElementDetails (только просмотр) ✅
│   └── InterfaceTable (только отображение интерфейсов) ✅
└── ElementEditor (Modal)
    ├── Используется ТОЛЬКО при редактировании/создании ✅
    └── Интерфейсы управляются ЗА ПРЕДЕЛАМИ стандартного потока ✅
```

**Почему это работает:**
1. ✅ InterfaceTable в ElementDetails больше не используется для редактирования
2. ✅ Редактирование интерфейсов происходит в отдельном модальном окне
3. ✅ Каждый ElementEditor имеет свой локальный state для интерфейсов
4. ✅ При сохранении - отправляются ВСЕ данные (элемент + интерфейсы) одновременно
5. ✅ Нет путаницы с глобальным состоянием интерфейсов

## Использование

### Создание нового СЭ
```
1. Клик "+ New Element" в левой панели
2. Открывается ElementEditor в режиме создания
3. Заполняем форму элемента
4. Клик "+ Add Interface"
5. Добавляем интерфейсы (имя, IP, MAC, уровень, подключение)
6. Клик "✅ Save Element"
7. Элемент создан вместе с интерфейсами
```

### Редактирование СЭ
```
1. Выбираем элемент в списке
2. Клик "✎ Edit" на элементе в списке ИЛИ в деталях
3. Открывается ElementEditor в режиме редактирования
4. Можем:
   - Изменить имя, тип, описание
   - Добавить новые интерфейсы
   - Отредактировать существующие интерфейсы
   - Удалить интерфейсы
5. Клик "✅ Save Element"
6. Все изменения сохранены
```

## API запросы

ElementEditor делает следующие запросы:

### При создании элемента:
```
POST /api/elements                           → создание элемента
POST /api/elements/{id}/interfaces          → для каждого интерфейса
```

### При редактировании элемента:
```
PUT /api/elements/{id}                      → обновление элемента
POST /api/elements/{id}/interfaces          → новые интерфейсы
PUT /api/elements/{id}/interfaces/{iid}     → обновление интерфейсов
DELETE /api/elements/{id}/interfaces/{iid}  → удаление интерфейсов
GET /api/elements/{id}                      → получение обновленного элемента
GET /api/available-interfaces               → для выбора подключений
```
