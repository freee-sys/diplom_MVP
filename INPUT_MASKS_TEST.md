# Тестирование маскирования входных данных

## Изменения

### 1. Удалена кнопка "Add Interface" из таблицы InterfaceTable
- Интерфейсы теперь можно добавлять ТОЛЬКО из ElementEditor при создании/редактировании элемента
- Таблица отображается как read-only в разделе Elements → выбранный элемент

### 2. Добавлено маскирование IP адреса (XXX.XXX.XXX.XXX)
- **Где:** ElementEditor и InterfaceTable при добавлении интерфейса
- **Поведение:**
  - Пользователь вводит: `192168111`
  - Система показывает: `192.168.1.1`
  - Нельзя вводить числа > 255 (становятся 255)
  - Максимум 4 группы по 3 цифры

### 3. Добавлено маскирование MAC адреса (XX:XX:XX:XX:XX:XX)
- **Где:** ElementEditor и InterfaceTable при добавлении интерфейса
- **Поведение:**
  - Пользователь вводит: `001A2B3C4D5E`
  - Система показывает: `00:1A:2B:3C:4D:5E`
  - Только шестнадцатеричные символы (0-9, A-F)
  - Автоматически в ВЕРХНЕМ РЕГИСТРЕ
  - Максимум 12 символов (6 байт)

---

## Тест 1: Маскирование IP адреса

### Этапы:
1. Откройте App на http://localhost:3000
2. Нажмите "Create Element" или "Edit" существующего элемента
3. В форме интерфейса в поле "IP Address" введите: `192168111`

### Ожидаемый результат:
- Система преобразует: `192.168.1.1`
- Все цифры подставлены с точками
- Символы кроме цифр и точек отклонены

### Дополнительный тест:
- Введите: `256.256.256.256`
- Ожидание: `255.255.255.255` (числа > 255 обрезаны)

---

## Тест 2: Маскирование MAC адреса

### Этапы:
1. В форме интерфейса в поле "MAC Address" введите: `001A2B3C4D5E`

### Ожидаемый результат:
- Система преобразует: `00:1A:2B:3C:4D:5E`
- Все буквы в ВЕРХНЕМ РЕГИСТРЕ
- Двоеточия добавлены автоматически каждые 2 символа

### Дополнительный тест:
- Введите: `00:1a:2b:3c:4d:5e` (нижний регистр)
- Ожидание: `00:1A:2B:3C:4D:5E` (преобразовано в ВЕРХНИЙ)

### Попытка ввести неверные символы:
- Введите: `00:1a:2b:3c:4d:5e:xyz`
- Ожидание: Символы xyz отклонены, остается `00:1A:2B:3C:4D:5E`

## Тест 3: Удаление кнопки "Add Interface"

### Проверка в Elements:
1. Перейдите на вкладку "Elements"
2. Нажмите на элемент в списке слева
3. Справа должна отобразиться таблица интерфейсов

### Ожидаемый результат:
- ❌ Кнопка "Add Interface" НЕ видна в таблице
- Интерфейсы отображаются в read-only режиме (только Edit и Delete)

### Как добавлять интерфейсы правильно:
1. Нажмите "Edit" на элемент
2. Откроется ElementEditor
3. Нажмите "Add Interface" в форме редактирования
4. Добавьте интерфейсы с маскированием
5. Сохраните элемент

## Тест 4: Полный сценарий создания элемента

### Шаги:
1. Нажмите "Create Element"
2. Введите:
   - Name: TestRouter
   - Type: Router
3. Нажмите "Add Interface"
4. В форме интерфейса:
   - Name: eth0
   - Type: Ethernet
   - IP Address: `192168110` → должно стать `192.168.1.10`
   - MAC Address: `001a2b3c4d5e` → должно стать `00:1A:2B:3C:4D:5E`
5. Нажмите "Add Interface" (кнопка в форме)
6. Добавьте второй интерфейс eth1
7. Нажмите "Save"

### Ожидаемый результат:
- ✅ Элемент создан с 2 интерфейсами
- ✅ IP и MAC адреса сохранены в правильном формате
- ✅ Таблица интерфейсов показывает оба интерфейса с масками

## Если что-то не работает

### Проблема: Маски не применяются
- Проверьте консоль браузера (F12 → Console)
- Проверьте, что вводите в правильное поле (IP Address / MAC Address)
- Попробуйте очистить кэш браузера (Ctrl+Shift+R)

### Проблема: Кнопка "Add Interface" все еще видна
- Проверьте, что изменения сохранены в InterfaceTable.js
- Перезагрузите страницу (F5)
- Проверьте, что вы ищете в разделе Elements (таблица интерфейсов)

### Проблема: Backend ошибки
- Проверьте, что backend запущен: `python app.py`
- Проверьте логи в терминале backend
- Убедитесь, что IP и MAC адреса в правильном формате перед отправкой
