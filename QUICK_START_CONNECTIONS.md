# 🚀 Быстрый старт: Функция "Связь"

## За 5 минут до первого соединения

### Шаг 1: Запустите приложение ✅

```bash
# В первом терминале (Backend)
cd backend
python app.py

# Во втором терминале (Frontend)
cd frontend
npm start
```

Приложение откроется на `http://localhost:3000`

### Шаг 2: Создайте первый элемент 📡

1. Перейдите в вкладку **Elements**
2. Нажмите **+ Add Element**
3. Введите:
   - **Name:** `Router_1`
   - **Type:** `Router`
   - **Description:** `Main core router`
4. Нажмите **Add Element**

### Шаг 3: Добавьте интерфейсы 🔌

Элемент `Router_1` должен быть выбран. Нажмите **+ Add Interface** и создайте:

**Интерфейс 1:**
- Name: `eth0`
- Type: `Ethernet`
- IP: `192.168.1.1`
- MAC: `00:11:22:33:44:55`
- Status: `up`
- Bandwidth: `1000`
- **Connection Level:** `L3` ← Новое поле!
- **Connect to Interface:** оставить пусто (пока нечего подключать)

Нажмите **Add Interface**

### Шаг 4: Создайте второй элемент 📡

1. Нажмите **+ Add Element**
2. Введите:
   - **Name:** `Router_2`
   - **Type:** `Router`
3. Нажмите **Add Element**

### Шаг 5: Добавьте интерфейс ко второму элементу 🔌

Выберите `Router_2` и нажмите **+ Add Interface**

**Интерфейс для Router_2:**
- Name: `eth0`
- Type: `Ethernet`
- IP: `192.168.2.1`
- MAC: `00:11:22:33:44:56`
- Status: `up`
- Bandwidth: `1000`
- **Connection Level:** `L3`
- **Connect to Interface:** оставить пусто (добавим после)

Нажмите **Add Interface**

### Шаг 6: Создайте соединение между элементами 🔗

Вернитесь к **Router_1** и нажмите **✎** рядом с интерфейсом `eth0`

В форме редактирования:
- **Connection Level:** оставить `L3`
- **Connect to Interface:** выберите **[Router_2] → eth0** ← Вот это главное!

Нажмите **Update Interface**

✨ Готово! На топологии появилась синяя линия между Router_1 и Router_2!

### Шаг 7: Просмотрите соединение на топологии 📊

1. Перейдите в вкладку **Topology**
2. Видите:
   - **Два круга** с названиями маршрутизаторов
   - **Синюю сплошную линию** между ними (L3 соединение)
   - **Dropdown меню** "Connection Level Filter" в верхней части

### Шаг 8: Используйте фильтр 🎯

Попробуйте изменить фильтр в верхней панели:
- Выберите **L2** → линия исчезнет (она L3)
- Выберите **L3** → линия появится снова
- Выберите **All** → видно все соединения

## 🎨 Цветовая кодировка

На топологии вы увидите линии разных цветов:

| Уровень | Цвет | Стиль | Значение |
|---------|------|-------|----------|
| L2 | 🟢 Зеленый | - - - - | Соединение на канальном уровне (Data Link) |
| L3 | 🔵 Синий | ━━━━━ | Соединение на сетевом уровне (Network) |
| L2/L3 | 🟣 Фиолетовый | ━ ━ ━ | Соединение на обоих уровнях |

## 📋 Таблица интерфейсов

В правой панели элемента видна таблица интерфейсов с новой колонкой **Connection**:

```
Интерфейс │ Статус │ Connection
───────────────────────────────────
eth0      │ up     │ L3 Connected ← синий с зеленым текстом
eth1      │ up     │ Not connected ← серый
eth2      │ down   │ L2 Connected ← зеленый
```

## 🆘 Частые вопросы

### Q: Dropdown интерфейсов пуст?
**A:** Убедитесь, что:
- ✅ У другого элемента есть хотя бы один интерфейс
- ✅ Этот интерфейс еще не подключен к текущему элементу
- ✅ Обновите страницу браузера (F5)

### Q: Линия не отображается на топологии?
**A:** Проверьте:
- ✅ Оба элемента видны на топологии
- ✅ Интерфейс второго элемента имеет обратную ссылку (reverse_interface_id)
- ✅ Фильтр соединений показывает нужный уровень
- ✅ Откройте DevTools (F12) и посмотрите консоль

### Q: Могу ли я создать L2 соединение?
**A:** Да! Просто выберите **L2** в поле "Connection Level" вместо L3. На топологии появится зеленая штрихованная линия.

### Q: Как удалить соединение?
**A:** Отредактируйте интерфейс и выберите "-- No Connection --" в поле "Connect to Interface". Линия исчезнет.

## 🔍 Примеры сценариев

### Сценарий 1: Коммутируемая сеть (L2)

```
Создайте два коммутатора (Switch_1, Switch_2)
Добавьте интерфейсы port1 к каждому
Connection Level: L2
Результат: зеленая штрихованная линия между коммутаторами
Использование: Анализ канального уровня, VLAN соединения
```

### Сценарий 2: Маршрутизируемая сеть (L3)

```
Создайте два маршрутизатора (R1, R2)
Добавьте интерфейсы eth0 к каждому
Добавьте IP адреса (R1: 10.0.0.1, R2: 10.0.0.2)
Connection Level: L3
Результат: синяя сплошная линия между маршрутизаторами
Использование: Анализ маршрутизации, IP соединения
```

### Сценарий 3: Иерархическая сеть (L2/L3)

```
Создайте 3 элемента: Core Router, Distribution Switch, Access Switch
Connection Core-Distribution: L3 (синяя)
Connection Distribution-Access: L2 (зеленая)
Connection Core-Access: L2/L3 (фиолетовая)
Использование: Визуализация многоуровневой архитектуры
```

## 💡 Советы и трюки

### Совет 1: Быстрое создание топологии
Добавляйте элементы и интерфейсы сначала, потом создавайте соединения. Так удобнее.

### Совет 2: Использование фильтра
Переключайте фильтр "All" → "L2" → "L3" → "All" для анализа разных уровней сети.

### Совет 3: Проверка соединений
Таблица интерфейсов показывает статус каждого интерфейса. Красная ячейка = не подключен.

### Совет 4: Именование
Используйте логичные имена:
- eth0, eth1 для Ethernet
- g0/0, g0/1 для GigabitEthernet
- ser0, ser1 для Serial
- lo0 для Loopback
