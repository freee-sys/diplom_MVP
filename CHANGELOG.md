# 📋 CHANGELOG - Версия 1.1.0

## 🆕 Новое (18 Января 2026)

### ✨ Основные функции

#### Топология сети (📡 Topology Tab)
- **Визуализация элементов** - Каждый элемент как интерактивный круг
- **Умное расположение** - Автоматическое размещение по сетке, кругу или спирали
- **Интерактивность** - Левый клик для редактирования, правый клик для меню
- **Контекстное меню** - Быстрые действия: редактировать, удалить
- **Иконки типов** - Быстрое определение: 🔀 Router, ⚡ Switch, 🔒 Firewall, 🚪 Gateway
- **Легенда и статистика** - Справка по типам, счетчик элементов
- **Адаптивный дизайн** - Работает на всех размерах экрана
