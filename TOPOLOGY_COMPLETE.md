## 🔧 Технические детали

### Размещение элементов
```
1 элемент    → центр (x = width/2, y = height/2)
2-4 элемента → сетка 2x2
5-8 элементов → круг (angle = index/total * 2π)
9+ элементов → спираль (angle = index/total * 4π)
```

### События пользователя

| Действие | Результат |
|----------|-----------|
| Левый клик на элемент | Переход в Elements, открыть для редактирования |
| Правый клик на элемент | Показать контекстное меню |
| Меню → Редактировать | То же что левый клик |
| Меню → Удалить | Удалить элемент с подтверждением |
| Клик вне меню | Закрыть меню |
| Нажать Escape | Закрыть меню |
| Наведение на элемент | Увеличить на 10%, изменить cursor |

### Иконки типов
- 🔀 Router - маршрутизатор
- ⚡ Switch - коммутатор
- 🔒 Firewall - брандмауэр
- 🚪 Gateway - шлюз
