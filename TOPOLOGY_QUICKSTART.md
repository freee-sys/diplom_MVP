# 🎯 Быстрый старт - Топология сети

## ⚡ За 30 секунд до работающей топологии

### Шаг 1: Убедитесь что приложение работает
```bash
# Если приложение еще не запущено:
# Windows: запустите start.bat
# macOS/Linux: запустите start.sh

# Проверка: откройте http://localhost:3000
```

### Шаг 2: Создайте несколько элементов
1. Откройте вкладку **Elements** (должна быть активной по умолчанию)
2. Нажмите кнопку **+ New Element**
3. Заполните форму:
   ```
   Name: Router-1
   Type: Router
   Description: Главный маршрутизатор
   ```
4. Нажмите **Save**
5. **Повторите** для 2-3 элементов разных типов

### Шаг 3: Откройте Топологию
1. Нажмите вкладку **📡 Topology** в верхней части
2. Вы увидите все созданные элементы на диаграмме!

## 🎮 Управление элементами

### Редактирование
```
Способ 1: Левый клик на элемент
  → откроется в Elements для редактирования

Способ 2: Правый клик → Редактировать
  → откроется в Elements
```

### Удаление
```
Способ 1: Правый клик → Удалить
  → подтвердите удаление

Способ 2: Откройте в Elements и нажмите Delete
```

## 💡 Советы

| Задача | Действие |
|--------|----------|
| Посмотреть всю сеть | Откройте вкладку Topology |
| Редактировать элемент | Левый клик на элемент или правый → Редактировать |
| Удалить элемент | Правый клик → Удалить |
| Добавить интерфейс | Откройте элемент в Elements и добавьте в таблице |
| Увидеть количество интерфейсов | Посмотрите на топологии под названием (🔌 N интерфейсов) |

## 🎨 Что видите на топологии

```
        🔀 Router
      Router-1
    🔌 2 интерфейса
    
    ⚡ Switch           🔒 Firewall
   Switch-1           Firewall-1
  🔌 3 интерфейса     🔌 1 интерфейс
```

### Иконки типов
- 🔀 **Router** - маршрутизатор
- ⚡ **Switch** - коммутатор  
- 🔒 **Firewall** - брандмауэр
- 🚪 **Gateway** - шлюз

## ❓ Проблемы?

### Топология не отображается
```
Решение:
1. Убедитесь что созданы элементы (посмотрите Elements)
2. Перейдите в Elements и вернитесь в Topology
3. Перезагрузите страницу (F5)
```

### Контекстное меню не появляется
```
Решение:
1. Используйте левый клик для редактирования
2. Проверьте что браузер позволяет контекстные меню
3. Отключите расширения браузера если они блокируют меню
```

### Элементы перекрываются на мобильном
```
Решение:
1. Это нормально для мобильных устройств
2. Работайте с элементами по одному
3. На большом экране они будут расположены лучше
```
