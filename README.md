# Virtual Network Element Management Application

MVP приложение для управления виртуальными сетевыми элементами (СЭ) с их интерфейсами и соединениями.

**Текущая версия:** 1.2.0 | **Статус:** ✅ Production Ready

## 🚀 Новое в версии 1.2.0

### Функция "Связь" (Connections/Links)
- ✅ Управление двусторонними соединениями между интерфейсами
- ✅ Поддержка уровней OSI (L2, L3, L2/L3)
- ✅ Визуализация соединений на топологии (цветные линии)
- ✅ Фильтрация соединений по уровню
- ✅ Новая колонка "Connection" в таблице интерфейсов

**Полный гайд:** [CONNECTIONS_GUIDE.md](CONNECTIONS_GUIDE.md)

## Функциональность (Версия 1.2.0)

### Сетевые элементы
- ✅ **Создание** - Добавление нового виртуального СЭ
- ✅ **Редактирование** - Изменение параметров СЭ
- ✅ **Удаление** - Удаление СЭ с его интерфейсами
- ✅ **Просмотр** - Отображение списка и деталей СЭ

### Интерфейсы (вложены в СЭ)
- ✅ **Таблица интерфейсов** - Каждая строка = один интерфейс
- ✅ **Создание** - Добавление интерфейса к СЭ
- ✅ **Редактирование** - Изменение параметров интерфейса
- ✅ **Удаление** - Удаление интерфейса
- ✅ **Просмотр** - Все интерфейсы доступны в таблице
- ✅ **Соединения** - Двусторонние связи между интерфейсами (НОВОЕ)

### 🔗 Соединения между интерфейсами (НОВОЕ в 1.2.0)
- ✅ **Уровни** - L2 (Data Link), L3 (Network), L2/L3 (Both)
- ✅ **Выбор** - Dropdown меню доступных интерфейсов
- ✅ **Визуализация** - Цветные линии на топологии
- ✅ **Фильтрация** - Показать/скрыть по уровню
- ✅ **Таблица** - Статус соединения для каждого интерфейса

### 📡 Визуальная топология сети
- ✅ **Топология** - Визуальное представление всех СЭ
- ✅ **Интерактивные элементы** - Нажмите на элемент для редактирования
- ✅ **Контекстное меню** - Правый клик для редактирования/удаления
- ✅ **Умное расположение** - Автоматическое расположение элементов
- ✅ **Иконки типов** - Быстрое определение типа элемента
- ✅ **Легенда** - Справка по типам элементов
- ✅ **Соединения** - Линии между связанными элементами (НОВОЕ)
- ✅ **Фильтр** - Управление видимостью соединений (НОВОЕ)

### Поля интерфейса
- Имя (Name)
- Тип (Type) - Ethernet, Gigabit Ethernet, Serial, Loopback
- IP адрес
- MAC адрес
- Статус (up/down/disabled)
- Пропускная способность (Bandwidth)
- **Уровень соединения** (Level) - L2, L3, L2/L3 (НОВОЕ в 1.2)
- **Обратный интерфейс** (Reverse Interface) (НОВОЕ в 1.2)
- MAC адрес
- Статус (Up/Down/Disabled)
- Пропускная способность

## Быстрый старт

### Требования
- Python 3.8+
- Node.js 14+
- npm или yarn

### Backend

```bash
cd backend

# Установка зависимостей
pip install -r requirements.txt

# Запуск сервера
python app.py
```

API будет доступен на `http://localhost:5000`

### Frontend

```bash
cd frontend

# Установка зависимостей
npm install

# Запуск приложения
npm start
```

Приложение откроется на `http://localhost:3000`

## API документация

### Endpoints

#### Сетевые элементы

| Метод | Путь | Описание |
|-------|------|---------|
| GET | `/api/elements` | Получить все элементы |
| POST | `/api/elements` | Создать новый элемент |
| GET | `/api/elements/{id}` | Получить элемент по ID |
| PUT | `/api/elements/{id}` | Обновить элемент |
| DELETE | `/api/elements/{id}` | Удалить элемент |

#### Интерфейсы

| Метод | Путь | Описание |
|-------|------|---------|
| GET | `/api/elements/{id}/interfaces` | Получить все интерфейсы |
| POST | `/api/elements/{id}/interfaces` | Создать интерфейс |
| PUT | `/api/elements/{id}/interfaces/{ifId}` | Обновить интерфейс |
| DELETE | `/api/elements/{id}/interfaces/{ifId}` | Удалить интерфейс |

### Примеры запросов

#### Создание СЭ
```bash
curl -X POST http://localhost:5000/api/elements \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Router-1",
    "type": "Router",
    "description": "Main router"
  }'
```

#### Добавление интерфейса
```bash
curl -X POST http://localhost:5000/api/elements/{element_id}/interfaces \
  -H "Content-Type: application/json" \
  -d '{
    "name": "eth0",
    "type": "Ethernet",
    "ip_address": "192.168.1.1",
    "mac_address": "00:1A:2B:3C:4D:5E",
    "status": "up",
    "bandwidth": "1Gbps"
  }'
```

## 📡 Топология сети

Новая вкладка **Topology** предоставляет интерактивное визуальное представление всех сетевых элементов:

### Функции
- 🎨 **Визуализация** - Все элементы как круги с иконками
- 🖱️ **Интерактивность** - Клик для редактирования
- 📎 **Контекстное меню** - Правый клик для меню
- 🔤 **Иконки типов** - Быстрое определение типов
- 🔄 **Автоматическое расположение** - Умное размещение элементов
- 📊 **Статистика** - Отображение количества элементов

### Навигация

**Вкладка Elements (по умолчанию)**
```
📋 Elements  |  📡 Topology
```
Здесь вы управляете элементами:
- Создание новых СЭ
- Редактирование параметров
- Управление интерфейсами в таблице
- Удаление элементов

**Вкладка Topology**
```
📋 Elements  |  📡 Topology
```
Здесь вы видите визуальную топологию:
- Нажмите на элемент → перейдет в Elements для редактирования
- Правый клик → контекстное меню (редактировать/удалить)
- Легенда внизу показывает типы элементов

Подробнее: [TOPOLOGY_GUIDE.md](TOPOLOGY_GUIDE.md)
