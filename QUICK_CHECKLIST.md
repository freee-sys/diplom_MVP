## 🚀 КАК ИСПОЛЬЗОВАТЬ

### 1️⃣ Запустите приложение
```bash
# Терминал 1
cd backend && python app.py

# Терминал 2  
cd frontend && npm start
```

### 2️⃣ Откройте http://localhost:3000

### 3️⃣ Создайте соединение
1. Элемент → Интерфейс → Редактировать
2. Выберите Level (L2/L3/L2/L3)
3. Выберите Connect to Interface из dropdown
4. Сохраните
5. На топологии появится линия!

### 4️⃣ Используйте фильтр на топологии
- Откройте вкладку Topology
- Используйте dropdown "Connection Level Filter"
- Видите только нужные соединения
