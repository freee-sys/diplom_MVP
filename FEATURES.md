# Описание функциональности

## MVP Функции - Итерация 1

### ✅ Реализовано

#### 1. Управление сетевыми элементами (СЭ)

**Создание**
- Форма для ввода имени, типа, описания
- Валидация на стороне клиента
- Автоматическое присваивание UUID
- Сохранение времени создания и обновления

**Редактирование**
- Режим редактирования для каждого элемента
- Изменение имени, типа, описания
- Сохранение изменений на сервер
- Отображение актуального времени обновления

**Удаление**
- Подтверждение перед удалением
- Удаление элемента со всеми интерфейсами
- Автоматическое обновление списка

**Просмотр**
- Список всех элементов в левой панели
- Подробная информация при клике
- Отображение количества интерфейсов
- Автоматическое обновление при изменениях

#### 2. Управление интерфейсами

**Структура интерфейса**
```
├── name (обязательно)
├── type (Ethernet, Gigabit Ethernet, Serial, Loopback)
├── ip_address
├── mac_address  
├── status (up, down, disabled)
├── bandwidth
└── created_at (автоматически)
```

**Таблица интерфейсов**
- Каждая строка = один интерфейс ✓
- Все основные поля видны
- Компактное отображение
- Быстрое редактирование inline

**Создание**
- Кнопка "Add Interface" в правой панели
- Форма с полями интерфейса
- Валидация имени
- Добавление только к существующему элементу

#### 3. Визуальная топология сети 📡

**Новая вкладка Topology**
- Переключение между Elements и Topology
- Полноэкранное отображение топологии
- Интерактивные визуальные элементы
- Автоматическое обновление при изменениях

**Визуализация элементов**
- Каждый элемент как круг с иконкой
- Иконки по типам: 🔀 Router, ⚡ Switch, 🔒 Firewall, 🚪 Gateway
- Отображение названия, типа, количества интерфейсов
- Иконка для быстрого определения типа

**Автоматическое расположение**
- 1 элемент → в центре
- 2-4 элемента → сетка 2x2
- 5-8 элементов → круговое расположение
- 9+ элементов → спиральное расположение

**Интерактивность**
- ⬅️ Левый клик → редактирование в Elements
- ➡️ Правый клик → контекстное меню
- 🖱️ Наведение → увеличение элемента на 10%
- 🔵 Выбор → выделение и свечение

**Контекстное меню**
- ✎ Редактировать → перейти в Elements
- ✕ Удалить → удалить с подтверждением
- Отображение названия и типа элемента
- Закрытие при клике вне меню или Esc

**Визуальные элементы**
- Легенда с типами элементов
- Счетчик количества элементов
- Пустое состояние с подсказкой
- Советы по использованию

#### 4. Управление соединениями (Connections/Links)

**Расширение интерфейсов**
- Новое поле: "Уровень" (Level) - L2, L3, L2/L3
- Новое поле: "Обратный интерфейс" (Reverse Interface)
- Выпадающий список доступных интерфейсов из других элементов
- Автоматическое создание двусторонних соединений

**Визуализация соединений**
- SVG линии между элементами на топологии
- Цветовая кодировка по уровню:
  - L2: зеленая штрихованная линия
  - L3: синяя сплошная линия
  - L2/L3: фиолетовая пунктирная линия
- Отображение всех активных соединений

**Фильтрация соединений**
- Выпадающий список в верхней панели топологии
- Фильтры: All / L2 / L3 / L2/L3
- Счетчик соединений каждого уровня
- Быстрое переключение между уровнями

**Таблица соединений**
- Новая колонка "Connection" в таблице интерфейсов
- Цветовой индикатор статуса соединения
- Текст: "Not connected" или "[Level] Connected"
- Визуальное выделение подключенных интерфейсов

**Две вкладки навигации**

- Легенда с цветами уровней соединений

**Стили и оформление**

- Специальное оформление для связей

### 🔌 API Особенности

**Автоматические поля**
- `id` - UUID v4
- `created_at` - ISO 8601
- `updated_at` - ISO 8601 (обновляется при изменении)

**Валидация**
- Имя обязательно (не пусто)
- Тип выбирается из предопределенных значений
- IP адрес свободный формат (для гибкости)
- MAC адрес свободный формат

**Иерархия**
- Интерфейсы существуют только внутри элемента
- Удаление элемента удаляет все интерфейсы
- Интерфейсы не могут быть без элемента
