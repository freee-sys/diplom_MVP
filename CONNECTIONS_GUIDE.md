# Руководство по использованию функции "Связь" (Connections/Links)

## Описание функции

Функция "Связь" позволяет создавать двусторонние соединения между интерфейсами различных сетевых элементов (СЭ). Это необходимо для визуализации физических и логических сетевых путей на топологии и управления уровнями сетевых соединений (L2, L3).

## Основные компоненты

### 1. Поля интерфейса

Каждый интерфейс теперь содержит три новых поля:

#### **Уровень (Level)**
- **L2 (Data Link)** - соединение на канальном уровне (OSI Layer 2)
- **L3 (Network)** - соединение на сетевом уровне (OSI Layer 3)
- **L2/L3 (Both)** - соединение на обоих уровнях

Позволяет указать, на каком уровне OSI функционирует соединение между интерфейсами.

#### **Обратный интерфейс (Reverse Interface)**
- Выпадающий список всех доступных интерфейсов из других сетевых элементов
- При выборе интерфейса автоматически заполняется ID противоположного элемента (reverse_element_id)
- Создает двустороннее соединение между выбранными интерфейсами

### 2. Визуализация на топологии

#### **Линии соединения (Connection Lines)**
Линии на топологии визуально отображают соединения между элементами:

- **L2 соединения** (зеленый цвет): Штрихованная линия (- - - -)
- **L3 соединения** (синий цвет): Сплошная линия
- **L2/L3 соединения** (фиолетовый цвет): Пунктирная линия (- . - . -)

#### **Фильтр соединений (Connection Filter)**
Позволяет показывать/скрывать соединения определенного уровня:

- **All** - показать все соединения
- **L2** - только соединения на уровне Data Link
- **L3** - только соединения на уровне Network
- **L2/L3** - только соединения на обоих уровнях

Фильтр находится в верхней панели топологии рядом с кнопками управления.

## Пошаговое руководство

### Создание соединения между интерфейсами

1. **Откройте редактор интерфейсов**
   - Нажмите кнопку "Edit" рядом с нужным элементом на топологии
   - Перейдите в разделе "Interfaces"

2. **Добавьте новый интерфейс или отредактируйте существующий**
   - Нажмите "Add Interface" или кнопку "✎" рядом с интерфейсом

3. **Заполните форму интерфейса**
   ```
   Name: eth0
   Type: Ethernet
   IP Address: 192.168.1.1
   MAC Address: 00:11:22:33:44:55
   Status: up
   Bandwidth: 1000
   Connection Level: L3 ← выберите уровень
   Connect to Interface: [Router_2] → eth1 ← выберите противоположный интерфейс
   ```

4. **Сохраните интерфейс**
   - Нажмите кнопку "Add Interface" или "Update Interface"
   - Соединение будет автоматически создано в системе

### Просмотр соединений в таблице

В таблице интерфейсов отображается колонка "Connection":

- **"Not connected"** (серый текст) - интерфейс не подключен к другому интерфейсу
- **"L2 Connected"** (зеленый с подложкой) - соединение на уровне Data Link
- **"L3 Connected"** (синий с подложкой) - соединение на уровне Network
- **"L2/L3 Connected"** (фиолетовый с подложкой) - соединение на обоих уровнях

### Просмотр соединений на топологии

1. **Линии соединения автоматически отображаются**
   - После создания соединения на топологии появляется линия между элементами
   - Цвет линии зависит от уровня соединения

2. **Используйте фильтр для управления видимостью**
   - Откройте выпадающий список "Connection Level Filter" в верхней панели
   - Выберите нужный уровень для показа только соответствующих соединений

3. **Анализируйте сетевую топологию**
   - Зеленые штрихованные линии (L2) - соединения на канальном уровне
   - Синие сплошные линии (L3) - соединения на сетевом уровне
   - Фиолетовые пунктирные линии (L2/L3) - смешанные соединения

## Примеры использования

### Пример 1: Создание L3 соединения между маршрутизаторами

```
Элемент 1: Router_1
├─ Interface: eth0
│  ├─ IP: 192.168.1.1
│  ├─ Level: L3
│  └─ Reverse: Router_2 → eth0

Элемент 2: Router_2
├─ Interface: eth0
│  ├─ IP: 192.168.2.1
│  ├─ Level: L3
│  └─ Reverse: Router_1 → eth0

Результат на топологии: синяя сплошная линия между Router_1 и Router_2
```

### Пример 2: Создание L2 соединения между коммутаторами

```
Элемент 1: Switch_1
├─ Interface: port1
│  ├─ MAC: 00:11:22:33:44:01
│  ├─ Level: L2
│  └─ Reverse: Switch_2 → port1

Элемент 2: Switch_2
├─ Interface: port1
│  ├─ MAC: 00:11:22:33:44:02
│  ├─ Level: L2
│  └─ Reverse: Switch_1 → port1

Результат на топологии: зеленая штрихованная линия между Switch_1 и Switch_2
```

## API Endpoints

### Получить все соединения

```http
GET /api/connections
```

**Ответ:**
```json
[
  {
    "from_element_id": "uuid",
    "from_interface_id": "uuid",
    "from_interface_name": "eth0",
    "to_element_id": "uuid",
    "to_interface_id": "uuid",
    "to_interface_name": "eth1",
    "level": "L3"
  }
]
```

### Получить доступные интерфейсы для соединения

```http
GET /api/available-interfaces?element_id=<element_uuid>
```

**Ответ:**
```json
[
  {
    "element_id": "uuid",
    "element_name": "Router_2",
    "interface_id": "uuid",
    "interface_name": "eth0"
  }
]
```

### Создать интерфейс с соединением

```http
POST /api/elements/<element_id>/interfaces
```

**Тело запроса:**
```json
{
  "name": "eth0",
  "type": "Ethernet",
  "ip_address": "192.168.1.1",
  "mac_address": "00:11:22:33:44:55",
  "status": "up",
  "bandwidth": "1000",
  "level": "L3",
  "reverse_interface_id": "interface_uuid",
  "reverse_element_id": "element_uuid"
}
```

### Обновить интерфейс и его соединение

```http
PUT /api/elements/<element_id>/interfaces/<interface_id>
```

**Тело запроса:**
```json
{
  "name": "eth0",
  "type": "Ethernet",
  "ip_address": "192.168.1.1",
  "mac_address": "00:11:22:33:44:55",
  "status": "up",
  "bandwidth": "1000",
  "level": "L3",
  "reverse_interface_id": "interface_uuid",
  "reverse_element_id": "element_uuid"
}
```

## Возможные проблемы и решения

### Проблема: Соединение не отображается на топологии

**Решение:**
1. Убедитесь, что у обоих интерфейсов заполнено поле "Reverse Interface"
2. Проверьте, что оба элемента видны на топологии
3. Убедитесь, что фильтр соединений установлен на нужный уровень

### Проблема: Изменения не сохраняются

**Решение:**
1. Убедитесь, что вы нажали кнопку "Add Interface" или "Update Interface"
2. Проверьте консоль браузера на наличие ошибок (F12)
3. Убедитесь, что бэкенд сервер запущен и доступен

### Проблема: Нельзя выбрать интерфейс из выпадающего списка

**Решение:**
1. Убедитесь, что в системе существует хотя бы один другой элемент с интерфейсами
2. Убедитесь, что другой элемент не содержит более 5 интерфейсов
3. Обновите страницу браузера (F5)

## Технические детали

### Структура данных Interface

```javascript
interface Interface {
  id: string;                    // UUID
  name: string;                  // Название интерфейса
  type: string;                  // Тип: Ethernet, Serial, etc.
  ip_address: string;            // IP адрес
  mac_address: string;           // MAC адрес
  status: 'up' | 'down' | 'disabled'; // Статус
  bandwidth: string;             // Пропускная способность
  level: 'L2' | 'L3' | 'L2/L3'; // Уровень соединения
  reverse_interface_id: string;  // ID противоположного интерфейса
  reverse_element_id: string;    // ID противоположного элемента
  created_at: string;            // Дата создания
}
```

### Структура данных Connection

```javascript
interface Connection {
  from_element_id: string;       // ID исходного элемента
  from_interface_id: string;     // ID исходного интерфейса
  from_interface_name: string;   // Название исходного интерфейса
  to_element_id: string;         // ID целевого элемента
  to_interface_id: string;       // ID целевого интерфейса
  to_interface_name: string;     // Название целевого интерфейса
  level: 'L2' | 'L3' | 'L2/L3'; // Уровень соединения
}
```

## Лучшие практики

1. **Используйте логические имена интерфейсов**
   - eth0, eth1 для Ethernet
   - ser0, ser1 для Serial
   - lo0 для Loopback

2. **Убедитесь в согласованности уровней**
   - Оба интерфейса соединения должны иметь одинаковый уровень

3. **Документируйте соединения**
   - Используйте поле "Bandwidth" для указания скорости канала
   - Используйте поле "Status" для отслеживания рабочего состояния

4. **Используйте фильтры для анализа**
   - Включайте только L2 для анализа коммутационной топологии
   - Включайте только L3 для анализа маршрутизации
