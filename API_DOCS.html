🌐 Virtual Network Element API Documentation

Base URL

http://localhost:5000/api

Network Elements Endpoints

GET/elements

Get all virtual network elements

Response:

[
  {
    "id": "uuid",
    "name": "Router-1",
    "type": "Router",
    "description": "Main router",
    "interfaces": [],
    "created_at": "2024-01-18T...",
    "updated_at": "2024-01-18T..."
  }
]
POST/elements

Create a new network element

Request Body:

{
  "name": "Router-1",
  "type": "Router",
  "description": "Main router"
}
GET/elements/{id}

Get a specific network element

PUT/elements/{id}

Update a network element

Request Body:

{
  "name": "Router-1-Updated",
  "type": "Router",
  "description": "Updated router"
}
DELETE/elements/{id}

Delete a network element (and all its interfaces)

Interface Endpoints

GET/elements/{element_id}/interfaces

Get all interfaces for a network element

POST/elements/{element_id}/interfaces

Add an interface to a network element

Request Body:

{
  "name": "eth0",
  "type": "Ethernet",
  "ip_address": "192.168.1.1",
  "mac_address": "00:1A:2B:3C:4D:5E",
  "status": "up",
  "bandwidth": "1Gbps"
}
PUT/elements/{element_id}/interfaces/{interface_id}

Update an interface

DELETE/elements/{element_id}/interfaces/{interface_id}

Delete an interface

Quick Reference

Field Description Example
name Element or interface name Router-1, eth0
type Element: Router, Switch, Firewall, Gateway
Interface: Ethernet, Gigabit Ethernet, Serial, Loopback		 Router, Ethernet
status Interface status up, down, disabled
ip_address IPv4 address 192.168.1.1
mac_address MAC address 00:1A:2B:3C:4D:5E

Health Check

GET/health

Check API health status

Response: {"status": "healthy"}
