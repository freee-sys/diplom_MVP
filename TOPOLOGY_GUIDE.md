# 📡 Руководство по Топологии Сети

## Что такое Топология?

Топология сети - это визуальное представление всех ваших виртуальных сетевых элементов (СЭ) на интерактивной диаграмме. Это позволяет быстро увидеть структуру вашей сети и управлять элементами.

## ✨ Основные функции

### 1. **Визуализация элементов**
- Все элементы отображаются как круги с иконками
- Иконки зависят от типа элемента:
  - 🔀 **Router** - маршрутизатор
  - ⚡ **Switch** - коммутатор
  - 🔒 **Firewall** - брандмауэр
  - 🚪 **Gateway** - шлюз

### 2. **Умное расположение**
- **1 элемент** - в центре экрана
- **2-4 элемента** - в сетке 2x2
- **5-8 элементов** - по кругу (круговое расположение)
- **9+ элементов** - спиральное расположение

### 3. **Интерактивные элементы**

#### Клик на элемент
- **Левый клик** - открыть для редактирования во вкладке Elements
- **Правый клик** - показать контекстное меню

#### Эффекты при взаимодействии
- 🖱️ **Наведение** - элемент увеличивается на 10%
- 🔵 **Выбор** - элемент выделяется голубой рамкой и светится

### 4. **Контекстное меню**

При правом клике на элемент появляется меню с опциями:

```
┌─────────────────────┐
│ Router-1 | Router   │ ← Название и тип элемента
├─────────────────────┤
│ ✎ Редактировать    │
│ ✕ Удалить          │
└─────────────────────┘
```

**Опции:**
- **✎ Редактировать** - открыть элемент для редактирования
- **✕ Удалить** - удалить элемент (с подтверждением)

### 5. **Информация об элементе**

Под иконкой каждого элемента отображается:
- **Название** элемента
- **Тип** элемента
- **Количество интерфейсов** (🔌 N интерфейсов)

## 📖 Пошаговое руководство

### Как открыть Топологию

1. Откройте приложение Virtual Network Element Manager
2. Нажмите вкладку **📡 Topology** в верхней части экрана
3. Вы увидите все ваши сетевые элементы на диаграмме

### Как редактировать элемент через Топологию

**Способ 1: Левый клик**
1. Нажмите левую кнопку мыши на элементе
2. Вы будете перенаправлены во вкладку Elements с открытым элементом
3. Отредактируйте информацию в правой панели

**Способ 2: Контекстное меню**
1. Нажмите правую кнопку мыши на элементе
2. Выберите **✎ Редактировать**
3. Вы будете перенаправлены во вкладку Elements

### Как удалить элемент

1. Нажмите правую кнопку мыши на элементе
2. Выберите **✕ Удалить**
3. Подтвердите удаление в диалоговом окне
4. Элемент будет удален из топологии

### Как добавить новый элемент

Хотя добавление напрямую из Топологии невозможно, вы можете:
1. Перейти во вкладку **📋 Elements**
2. Нажать кнопку **+ New Element**
3. Заполнить форму и создать элемент
4. Вернуться в Топологию, где появится новый элемент

## 💡 Полезные советы

### Для быстрого управления
1. Используйте **правый клик** для быстрого редактирования/удаления
2. Используйте **левый клик** когда хотите отредактировать все детали
3. Количество интерфейсов видно сразу на диаграмме

### Для навигации
1. Если элементов много, топология автоматически расположит их оптимально
2. Элементы не перекрываются при нормальных размерах экрана
3. На мобильных устройствах элементы могут перекрываться - используйте элементы по одному

### Для отладки
1. **Нет элементов?** - Создайте первый элемент во вкладке Elements
2. **Элементы скрыты?** - Проверьте размер экрана браузера
3. **Контекстное меню не появляется?** - Убедитесь что браузер позволяет контекстные меню

## 🔄 Работа с интерфейсами

### Просмотр интерфейсов элемента
1. Нажмите на элемент (левый клик)
2. Перейдите во вкладку Elements
3. Отредактируйте интерфейсы в таблице справа

### Добавление интерфейса
1. Откройте элемент
2. В таблице интерфейсов нажмите **+ Add Interface**
3. Заполните форму добавления
4. Нажмите **Save**

## 🐛 Решение проблем

### Проблема: Контекстное меню не появляется
**Решение:** 
- Убедитесь что браузер позволяет контекстные меню
- Отключите расширения браузера которые могут блокировать контекстные меню
- Используйте левый клик для редактирования вместо правого

### Проблема: Элементы перекрываются
**Решение:**
- На мобильных устройствах это нормально
- На большом экране попробуйте увеличить размер окна браузера
- Работайте с элементами по одному

### Проблема: Топология не обновляется после изменений
**Решение:**
- Перезагрузите страницу (F5)
- Переключитесь на Elements и обратно на Topology
- Проверьте что API сервер работает (посмотрите логи)

### Проблема: Новые элементы не появляются на Топологии
**Решение:**
- Вернитесь во вкладку Elements и убедитесь что элемент создан
- Переключитесь обратно на Topology
- Если не помогает, перезагрузите страницу

## 📱 Адаптивность

Топология работает на всех размерах экрана:

### Десктоп (> 1200px)
- Элементы расположены оптимально
- Достаточно места для всех элементов
- Комфортно для работы

### Планшет (768px - 1199px)
- Элементы могут быть компактнее
- Может потребоваться скролл
- Контекстное меню адаптировано

### Мобильный (< 768px)
- Элементы расположены вертикально
- Может потребоваться скролл
- Работайте с элементами по одному

## ❓ Часто задаваемые вопросы

**Q: Могу ли я перемещать элементы на топологии?**
A: Нет, в текущей версии элементы расположены автоматически. Планируется добавить перетаскивание в будущих версиях.

**Q: Какое максимальное количество элементов можно добавить?**
A: Теоретически неограниченно, но рекомендуется не более 50 элементов для оптимальной производительности.

**Q: Как сделать скриншот топологии?**
A: Используйте встроенную функцию скриншота вашей ОС (Print Screen или Fn+Print Screen на ноутбуках).

**Q: Можно ли экспортировать топологию?**
A: В текущей версии нет, но это планируется для будущих версий.

**Q: Почему элементы не в том порядке что я ожидал?**
A: Топология использует оптимальный алгоритм расположения в зависимости от количества элементов.
